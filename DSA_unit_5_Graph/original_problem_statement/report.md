## Problem Statement

develop a c++ program to represent a weighted graph of campus buildings and cable installation costs. apply kruskal's algorithm to sert candidate edges by weight and select edges that connect all buildings without forming a cycle. display the selected minimum spanning tree edges and their total cost 




## Conclusion

By utilizing Kruskal's Algorithm, this application guarantees an optimal infrastructure layout. Sorting the installation paths ensures greedy cost optimization, while the Disjoint Set Union (DSU) structure guards against circular dependencies. The resulting program successfully yields a fully connected layout using the absolute minimum deployment budget.
